# Campus Study Spot Finder

A mobile-first campus study recommendation app built with Next.js. It helps students find nearby quiet study spaces, coworking-friendly rooms, silent cafés, and campus-friendly spots based on their current location and preferred study mode.

## Features

- Live location-aware recommendations
- Study mode filtering for deep focus, group review, and quick recharge
- Nearby space rankings with distance and category labels
- Saved favorites using local storage
- Quick assistant chat for common study queries
- Community review section for student feedback

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide icons

## Local development

```bash
npm install
npm run dev -- --hostname 0.0.0.0
```

Then open:

```text
http://localhost:3000
```

## Production build

```bash
npm run build
```
